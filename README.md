# Generative AI Programming — Weekly Exercises

Weekly programming exercises completed as part of my Generative AI Programming 
module, exploring Python fundamentals, data processing, unit testing, and 
using AI coding assistants effectively as part of the development workflow.

## Highlights
- **week5 / week7**: Unit-tested Python modules (expense tracking, shop 
  inventory) with dedicated test suites
- **week8**: Comparing prompt engineering approaches (vague vs. detailed vs. 
  persona-based prompts) for AI-assisted development
- **week3 / week4**: Data filtering and generation exercises

For a complete standalone project from this module — a full bus ticketing 
system with SQLite, authentication, and an automated test suite — see 
[fly-on-wheels-bus-ticketing](https://github.com/jamesob1100/fly-on-wheels-bus-ticketing).
